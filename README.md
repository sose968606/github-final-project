# Simple Interest Calculator

This project is part of the Introduction to Git and GitHub final project.

## Description

This project contains a Bash script that calculates simple interest based on the principal amount, rate of interest, and time.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Project Files

- README.md
- LICENSE
- CODE_OF_CONDUCT.md
- CONTRIBUTING.md

## Usage

The simple-interest.sh script asks the user to enter:

1. Principal amount
2. Rate of interest
3. Time in years

It then calculates and displays the simple interest.
