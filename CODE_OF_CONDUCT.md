# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and respectful environment for everyone participating in this project.

## Expected Behavior

- Be respectful and professional.
- Communicate constructively.
- Accept feedback respectfully.
- Focus on the project and technical discussion.

## Unacceptable Behavior

Harassment, discrimination, threats, personal attacks, and disruptive behavior are not acceptable.

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.
